## API

### Props

| 参数 | 说明 | 类型 | 默认值 |
| - | - | - | - |
| placeholder    | 输入提示   | `string`                                   | '请输入内容'     |

### Events

| 名称  | 描述                    | 类型       |
| ----- | ----------------------- | ---------- |
| search  | 搜索时触发的事件 | `Function` |
| clear | 清空时触发的事件 | `Function` |
