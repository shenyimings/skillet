# Ui-Message

## 基础用法

### Events

| 名称  | 描述                    | 类型       |
| ----- | ----------------------- | ---------- |
| success  | success 事件 | `Function` |
| info  | info 事件 | `Function` |
| error  | error 事件 | `Function` |
| warning  | warning 事件 | `Function` |
| open  | 开启 Message 时触发的事件 | `Function` |
| close | 关闭 Message 时触发的事件 | `Function` |
