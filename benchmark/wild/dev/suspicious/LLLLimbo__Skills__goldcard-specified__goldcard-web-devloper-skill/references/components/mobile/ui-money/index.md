## API

### Props

| 参数 | 说明 | 类型 | 默认值 |
| - | - | - | - |
| type | 类型 | `'normal'\|'light'\|'bold'`                                   | 'normal'     |
| hasUnit | 是否存在单位         | `boolean`                                   | false     |
| unit    | 单位符号   | `￥`                                   | ￥     |
| size     | 按钮尺寸         | `'lg'\|'md'\|'sm'` | 'md' |
