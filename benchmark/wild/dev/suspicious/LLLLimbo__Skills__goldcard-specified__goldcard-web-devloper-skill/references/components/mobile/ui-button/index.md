## API

### Props

| 参数 | 说明 | 类型 | 默认值 |
| - | - | - | - |
| type | 类型 | `'normal'\|'primary'\|'link'\|'secondary'\|'transparent'\|'lighter'`                                   | 'normal'     |
| disabled | 是否禁用         | `boolean`                                   | false     |
| round    | 是否为圆角按钮   | `boolean`                                   | false     |
| loading  | 是否为加载中状态 | `boolean`                                   | false     |
| size     | 按钮尺寸         | `'lg'\|'md'\|'sm'\|'min'\|'xlg'` | 'lg' |
