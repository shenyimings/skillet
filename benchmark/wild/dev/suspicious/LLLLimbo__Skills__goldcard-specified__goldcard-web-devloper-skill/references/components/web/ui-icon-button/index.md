# Ui Icon Button

图标按钮组件，基于 UiButton 封装的图标按钮组件，支持自定义图标和样式。

## 示例

@[demo vue](./icon-button-demo1.vue)

## 属性

| 属性名 | 类型 | 说明 |
| --- | --- | --- |
| name | `string` | 字体类名+图标类名, 参考[前端部自建图标字体平台](https://front-web.jinka.cn/base/font) 或三方字体图标平台 |
| color | `string` | 图标颜色 |

继承 UiButton 的所有属性。

## 事件

继承 UiButton 的所有事件。

## 样式类

- `.icon-button` - 图标按钮组件根元素
