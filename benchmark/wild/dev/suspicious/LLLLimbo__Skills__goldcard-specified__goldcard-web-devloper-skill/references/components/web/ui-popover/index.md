# Ui Popover

Popover 弹出框

## 基础用法

```vue
<template>
 <ui-popover
    placement="bottom"
    title="标题"
    :width="200"
    trigger="click"
    content="这是弹出框内容"
  >
    <template #reference>
      <ui-button class="m-2">Click to activate</ui-button>
    </template>
  </ui-popover>
</template>
```
